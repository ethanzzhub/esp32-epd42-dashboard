## 评估过的方案（按时间顺序）

### 起点：S3 + 2.8" IPS（¥70）

用户嫌性价比低。判断是：**¥70 不是被宰，是买错了形态** —— 同样预算已有「主板 + 大屏」一体的成品板。

### 候选对比

| 方案 | 尺寸/分辨率 | 主控 | 参考价 | 面积 | MicroPython 兼容 |
|---|---|---|---|---|---|
| 现有 S3 + 2.8" | 2.8" 240×320 IPS | S3 | ¥70 | 2423mm² | ★★★★★ |
| 只换屏 | 3.5"/4.0" SPI IPS | 复用 | ¥35–60 | 1.5–1.9× | ★★★★★ |

| CYD / JC2432W328 | 2.8" 240×320 TN | 老 ESP32 无 PSRAM | ¥30–45 | 2423mm² | ★★★★★ |

面积换算（mm²）：2.8"=2423、4.2"(4:3)=5393、4.26"=5176、4.3"(16:9)=5118、7"=13930。

### 被否决的

- **亦亚徽 EP4305S-V1（4.3" 800×480，ST7265，RGB 裸屏）**：ST7265 的 RGB 模式无用户 GRAM，主控要以 20–30MHz 像素时钟**持续推帧**，768KB 帧缓冲超 S3 SRAM 必须放 PSRAM + DMA；且是玻璃裸屏，需转接 PCB + 背光升压电路。MicroPython 驱动不了。
- **¥38 三色墨水屏「日历传图」套件**：驱动板烧死厂商日历程序，**不可编程**，是成品小电器不是开发板。且三色刷新比黑白更慢。
- **CYD 2.8"（¥30–45）**：价格砍半但 TN 屏 + 老 ESP32 无 PSRAM，是全面降级不是升级。
- **7" RGB**：硬件便宜，但要整套迁到 ESP-IDF + LVGL，贵的是固件重写。

### 4.26"(800×480 SSD1677) vs 4.2"(400×300 SSD1619A)

- 物理面积：4.2" **5393mm²** 反而略大于 4.26" 5176mm²，且 4:3 更方正。
- 分辨率：800×480 = 219 DPI vs 400×300 = 120 DPI → 4.26" 字更锐利，远看像打印；4.2" 适合半米到一米看。
- **刷新耗时与分辨率无关**（电泳粒子翻转由驱动波形决定；48KB vs 15KB 经 40MHz SPI 只差十几 ms）。全刷同为 2–4s 量级。
- 关键差异在**局部刷新**：4.26" 规格书明确 0.7s；4.2" 视批次（SSD1619A/UC8176/IL0398）未必支持 → 下单前必问客服。**已确认支持**（约 0.5s）才拍板。
- 若不支持局部刷，就得每 3–5 分钟全刷一次（4s 闪屏），放办公桌上会被同事注意到。

### 黑白 vs 三色

| | 黑白两色 | 三色（黑白红） |
|---|---|---|
| 全屏刷新 | **2–4s** | 15–20s（红粒子惰性大） |
| 局部刷新 | **0.5–0.7s，可用** | 基本不可用 |
| 帧缓冲 | 48KB（800×480） | 96KB（黑白层+红层） |
| 对比度 | 白底纯白 | 白底偏灰，红偏橙红 |
| 价格 | 便宜 | 明显贵 |

红色诱惑不成立：设计从一开始就是**无符号数字 + 加框表示跌**，不用颜色；且真要上红，e-paper 的红是橙红，与「跌=绿」的中国习惯也对不上。想要灰阶可用 Floyd–Steinberg 抖动在黑白屏上模拟。

## 供电 / 电池

**默认：有插座就别买电池**（长期 24h 浮充的锂电会鼓包）。

没插座时：

| 件 | 要求 | 价格 |
|---|---|---|
| 18650 | 2000–3500mAh，**必须品牌带保护板** | ¥15–30 |
| 带锂电接口的主控板（如 DFRobot FireBeetle 2 ESP32-S3） | 睡眠 25–80µA | ¥50–70 |
| 或普通板 + TP4056+升压一体模块 | 挑静态电流 <50µA 的 | ¥5–10 |

续航瓶颈是**每次连 WiFi**（80mA × 1–3s），不是刷屏（50mA × 0.7s）。普通板深度睡眠 1–3mA → 约 2 个月；低功耗板 → 3–6 个月。刷新间隔设 5–15 分钟可拉长续航。

单节 18650（3.0–4.2V）**不能直接接普通开发板的 5V/VIN**（板载 LDO 需 ≥4.3V，一放电就反复重启），必须经升压模块。屏统一从开发板 **3.3V** 取电，别把电池直供屏的 3V3（驱动板会升压到 ±15V，输入超压会烧）。

不推荐：充电宝（小电流自动关机）、纽扣电池（带不动 WiFi 峰值）、杂牌虚标 18650。
